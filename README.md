# 考场语音播报系统

> 纯本地化考场音频应急管理系统。支持时间段管理、本地音频库、拖拽绑定、定时播报、外部设备管理。蓝白色调，简洁实用。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📋 时间段管理 | 最多 10 个时间段，每个可绑定音频 + 设定定时播报时间 |
| 🎵 本地音频库 | 扫描 `audio/` 文件夹，支持 mp3/wav/ogg/flac/aac/m4a/wma |
| 🖱️ 拖拽交互 | 音频库拖拽绑定到时间段，时间段之间拖拽排序 |
| ⏰ 定时播报 | 设定每个时间段的触发时间（HH:MM），到点自动播放 |
| 🔊 设备管理 | 支持选择蓝牙/有线音频输出设备，一键打开系统蓝牙设置 |
| 📤 批量导入 | 拖拽多个文件上传，支持自定义命名 |
| ✏️ 音频管理 | 重命名、删除、试听预览（3 秒） |
| 💾 配置持久化 | 时间段配置自动保存，关闭再开配置不丢 |
| 🪟 桌面窗口 | 基于 pywebview 的原生桌面窗口，非浏览器标签页 |

---

## 🏗️ 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Flask（本地 127.0.0.1 服务） |
| 前端 | 原生 HTML + CSS + JavaScript |
| 桌面容器 | pywebview（Windows 原生窗口） |
| 音频播放 | HTML5 Audio + Web Audio API |
| 数据存储 | JSON 文件（`data/config.json`） |

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Windows 10/11（pywebview 桌面窗口）
- 浏览器端可用：Chrome / Edge

### 安装

```bash
pip install -r requirements.txt
```

### 运行

```bash
# 方式一：桌面窗口模式（推荐）
python app.py

# 方式二：浏览器模式
# 先启动 Flask：
python -c "from app import app; app.run(host='127.0.0.1', port=5000)"
# 然后浏览器打开 http://127.0.0.1:5000
```

### 添加音频
1. 将 mp3/wav 文件放入 `audio/` 文件夹
2. 或在应用内点击"选择文件"/拖拽上传

## 📝 使用说明

### 创建时间段
点击右下角 `+ 增加时间段` 按钮，最多创建 10 个。

### 绑定音频
- **拖拽**：从底部音频库拖动音频到时间段
- **点击**：点击时间段空白处，从弹出菜单选择

### 播放
- 点击时间段的 ▶ 按钮播放
- 点击顶部 `■ 全部停止` 停止所有

### 定时播报
- 在每个时间段输入触发时间（如 `08:00`）
- 勾选顶部 `定时播报` 开关
- 到时间自动播放对应音频

### 设备管理
- 点击 `🔌 设备管理` 展开面板
- 选择蓝牙/有线输出设备
- 点击 `🔍 蓝牙配对` 打开系统蓝牙设置
